# 고도화 구현 및 검증 보고

이 문서는 확장 API 추가 전 정적 고도화 검증의 기록입니다. 현재 확장 기능·환경·마이그레이션·외부 출시 조건은 [확장안 대응표](expansion-implementation.md)와 [서버 운영](backend-operations.md)을 따릅니다.

검증일: 2026-10-07. Windows, Node 22.22.3, npm 10.9.8에서 실행했습니다. 실제 공개 배포 결과와 로컬 검증을 구분합니다.

## 반영한 기능

- 기존 다크 박물관 디자인, 좌측 레일, 주요 메뉴 6개, 홈 진입 카드 4개와 정적 JSON 발행 구조를 유지했습니다.
- 홈의 공개 범위·추천 이유·집계를 실제 공개 데이터와 연결했습니다.
- 검색은 한국어·검증된 영문 별칭·인물·장소·기관, 주제·지역·유형·시대·원문·저장 조건, 정렬·페이지를 지원합니다. 검색 URL, 빠른 상세 이동 후 복귀와 읽기 위치를 보존합니다.
- 상세는 설명·연대·인물·장소·주장별 근거·자료 유형·기관·권리·확인 위치·해석의 한계·검토 상태·정정 이력을 제공합니다.
- 주제 질문, 실제 연표, 독립 컬렉션 2개와 스토리 2개, 읽기 순서·학습 질문·입문 용어 안내를 제공합니다.
- 기기 내 저장·개인 메모·최근 열람·읽기 위치·글자 크기·비교·인용 복사·공유·인쇄·백업/복원·선택적 이용 횟수 집계를 연결했습니다. 손상·제한 저장소와 미확인 가져오기 ID를 처리합니다.
- 정정 제안은 검증한 내용을 파일로 생성합니다. 서버 접수가 완료되었다고 표시하지 않습니다.
- canonical·JSON-LD·사이트맵·RSS·공유 카드·모바일 공개 데이터·최소 검색 인덱스·콘텐츠 hash를 생성합니다. 히어로는 기존 이미지로부터 WebP 크기별 자산을 만듭니다.
- 모바일 앱은 실제 공개 데이터 조회·형식 검증·검색·상세·공유·기기 저장·오프라인 캐시와 손상 보관함의 명시적 백업 복구를 제공합니다.
- 콘텐츠 감사·발행 게이트·출처 주소 검사, PR/main 검사, 배포 후 SHA 확인, 이전 승인 SHA 복구 절차와 환경 문서를 추가했습니다.

세부 구현 위치와 서버 의존 기능은 [요구사항 대응표](requirements-map.md), [서비스 경계](service-boundaries.md)에서 확인할 수 있습니다.

## 콘텐츠와 데이터 보존

원본 수집 파일 28개의 SHA256 보존 검사가 통과했습니다. 기록 31개의 기존/신규 URL을 생성하고, 출처를 대조한 4개 기록만 공개 탐색·검색·추천·사이트맵·피드에 포함합니다. 나머지 27개는 원본과 주소를 보존한 검토 안내이며 관련 없는 수집 요약을 다시 사건 해설로 노출하지 않습니다.

공개 기록 4개는 source-checked이며 humanReviewed=false입니다. 기관 자료를 대조한 상태와 역사 전문가 또는 사람의 승인을 구분합니다. 기관 해설을 사료 전문으로 표시하지 않습니다. 자료 8개의 주소 도달 검사는 8/8 통과했으며 주소 응답이 내용의 사실성을 보증하지 않습니다.

새로운 완전한 v2 JSON 기록도 본문·출처·인물·검수 상태를 유지한 채 기존 인덱스에서 발행됩니다. 잘못된 v2는 레거시로 낮추지 않고 검증 오류를 냅니다. 공개 산출물과 모바일·RSS도 같은 합본 계약을 사용합니다.

## 환경·배포·미검증 범위

데이터베이스와 DB 마이그레이션은 없습니다. 공개 URL·모바일 조회 URL·검사 호스트·release SHA·미리보기 포트/경로·빌드 프로필은 [.env.example](../.env.example)과 [배포 문서](deployment.md)에 정의했습니다. 비밀값을 추가하지 않았습니다.

배포 하위 경로 검사는 https://kenitoa.github.io/warsachive를 metadata 기준으로 빌드한 산출물을 loopback에서 제공한 검사입니다. 실제 사이트에 이번 변경을 배포하거나 push하지 않았습니다. 로컬 release의 gitSha는 기존 HEAD이며, 미커밋 변경을 포함하는 운영 배포 SHA 검증 증거가 아닙니다.

다음은 별도 미완료 또는 미검증 항목입니다.

- 공개 기록의 사람 검수와 보류 기록 27개의 개별 근거·관련성 검토.
- 실제 Linux Actions 실행, GitHub 권한·브랜치 보호·HTTPS 설정과 공개 배포 후 SHA·장애 복구 확인.
- 실제 Android/iOS 기기, APK/IPA·서명·스토어, 스크린리더·실제 확대/보조기기 검수. Android export는 네이티브 설치 패키지가 아닙니다.
- 이 정적 검증 시점에는 인증된 관리자·계정 동기화·실제 제보 접수·업로드·결제·AI 서버 구현을 검증하지 않았습니다. 이후 확장 구현의 현재 범위와 검증은 [확장안 대응표](expansion-implementation.md) 및 [확장 검증 보고](expansion-verification.md)를 따릅니다.
- 빌드·Expo 도구의 미해결 전이 취약점 28개. 호환성 확인을 거친 제한적 패치와 남은 원인·영향·추적 조건은 [보안 문서](security.md)에 기록했습니다.
