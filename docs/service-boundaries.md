# 정적 서비스와 서버·외부 연동 경계

정적 공개 웹과 인증된 API를 분리한다. API에 구현한 기능과 실제 외부 공급자·사람 검수·운영 배포 증거는 별개다. [확장안 대응표](expansion-implementation.md), [API 계약](api-contracts.md), [서버 운영](backend-operations.md)에 현재 경로를 정리했다.

| 기능 | 필요한 계약과 인프라 | 출시 조건 |
| --- | --- | --- |
| 비공개 관리자 | 역할별 CMS·버전·독립 승인·이력 복구·감사·서명 발행 구현 | 실제 운영자와 최종 검수 |
| 사용자 제보 | SQLite 실제 접수 번호·상태·담당 검토·origin/CSRF/속도 제한 | 실제 응답 담당과 보관 정책 |
| 계정·동기화 | scrypt/HttpOnly 세션·소유권·버전·선택형 병합·내보내기/삭제 구현 | 운영 HTTPS·같은 사이트 쿠키·전달 서비스 |
| 공동 기여 | 연구/수업 공간·초대·역할·제출·피드백·정정 moderation 구현 | 실제 사람 승인·교육/기관 운영 |
| 파일 업로드 | 검수자 비공개 근거 파일·5MiB magic/MIME·랜덤 이름·해시·인증 다운로드 | 공개 이미지/원문은 실제 권리 승인과 별도 안전한 미디어 제공 필요 |
| 유료 교육·결제 | 서버 상품·Stripe checkout·서명 웹훅·멱등성·환불 요청/검토/부분 환불 구현 | 실제 sandbox·약관·환불 정책·live gate |
| AI 보조 | 실제 Responses 어댑터·공개 자료 범위·section 인용 검사·출력/요청 상한 구현 | 실제 평가·비용·공급자 설정; 기본 비활성 |
| 분석·전달 | 선택형 기기 집계·API/worker 지표·알림 outbox 구현 | 외부 분석·메일 구독은 별도 동의/거부 계약 확보 뒤 제공 |
| 다국어 | locale 원문 버전/제목/요약·승인 상태·공개 projection 구현 | 실제 번역 승인0; 본문/메뉴 전체 번역은 완성·검수 뒤 공개 |

실제 API 주소를 설정하지 않은 배포에서는 연결이 필요하다고 표시한다. 공급자가 없는 reset·결제·AI에 성공 메시지나 목 결과를 생성하지 않는다. 공개 정적 사이트와 기존 ID·주소·기기 보관함은 유지한다. 공개 댓글, 임의 외부 URL의 서버 fetch, 권리 없는 원문·이미지 복제는 제공하지 않는다.
