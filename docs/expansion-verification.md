## 데이터와 운영 경계

- 원본 28개 파일의 바이트와 기존 기록 ID·주소를 유지하는 검사가 성공했다.
- 개인 연구·보관함 버전 충돌·계정 데이터 소유권·공동 공간 역할·제출/피드백 버전을 DB와 HTTP에서 검사했다.
- CMS 수정/복구 시 승인 무효화, 작성자와 다른 검수자 승인, 실제 버전 hash 발행, 서명 변조 거절과 보류 tombstone 유지가 성공했다.
- 비공개 첨부는 기록/출처 관계, 역할, 형식, 크기, 불변 파일명, SHA-256과 다운로드 헤더를 검사했다. 공개 산출물에 포함되지 않았다.
- DB 온라인 백업과 DB/첨부 bundle의 새 경로 복구, 원본 보존, 손상·경로 조작·심볼릭 링크 거절을 검사했다.
- API/worker 독립 프로세스의 동시 마이그레이션, IPC 종료 메시지와 부모 disconnect 시 정상 종료/SQLite 보존을 검사했다.
- 결제·환불은 주입한 공급자 응답으로 서버 금액, 소유권, 서명, 멱등성, 동시/중복/역순 응답과 결과 미확정 복구를 검사했다.
- AI는 주입한 공급자 응답으로 구조화 인용·공개 자료 경계와 서비스 일일 호출 예약/실패 소비/재시작 보존을 검사했다. 실제 생성 답변의 역사적 정확성을 평가한 것은 아니다.
- Docker/compose/CI 설정은 YAML 파싱·런타임 import graph·비루트 및 영속 경로 정의를 검토했다. 이 Windows 호스트에는 Docker가 없어 실제 Linux 컨테이너 실행은 하지 않았다.

## 남은 출시 조건

공개 source-checked 자료 4건은 사람 최종 검수 완료가 아니다. 외국어 승인 번역·검증 좌표·실제 IIIF manifest는 현재 각각 0건이며 기관 허락·계약을 임의로 만들지 않았다. 번역 기반의 현재 범위는 제목/요약과 원문 버전 검증이다. 전체 본문·메뉴와 외국어 페이지는 실제 번역 완성·검수 후 연결해야 한다.

실제 Stripe sandbox/live·OpenAI 답변 평가·이메일 전달, Linux/TLS/영속 volume·운영 배포와 복구 훈련, Android/iOS 실기기·보조 기술·외부 이용자 검사는 미검증이다. 외부 키나 승인이 없으면 해당 기능은 비활성이며 성공 결과를 만들어 표시하지 않는다.

전체 도구/Expo 전이 의존성 감사에는 28개 경고(높음23/중간5)가 남아 있다. 웹/API 운영 의존성 감사는 0개다. 원인·호환성 범위와 재검토 조건은 [보안 문서](security.md)에 기록했다. Node SQLite 실험적 경고, 단일 SQLite 쓰기 특성과 프로세스별 속도 제한은 운영 규모를 늘리기 전에 검토한다.

이 세션에서는 커밋·push·운영 배포를 수행하지 않았다. 저장소 권한·실제 CI 실행·배포 후 SHA 확인은 외부 실행 증거가 필요하다.
