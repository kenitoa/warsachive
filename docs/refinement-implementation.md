## 운영 활성화와 실제 증거

현재 출처 대조 공개 기록 4개와 공개 보류 27개는 유지한다. 사람의 최종 승인, 승인된 전체 번역, 확인된 좌표, 재사용 승인 미디어를 새로 만들어 넣지 않았다. 전체 번역·지도·IIIF·권리 허가는 필요한 실물 증거와 검수가 등록되기 전에는 보류한다.

외부 이메일의 실제 전달, Stripe 실제 결제·환불, 유료 상품/기관 계약, 실제 AI 모델 평가, 공개 CI/CD 및 Docker 실행, 실물 모바일 기기·스크린리더·외부 사용자 조사·현장 성능은 환경/운영자의 실제 확인이 필요하다. 구현된 차단 조건과 fixture 검사는 이 증거를 대신하지 않는다. 자동 시험을 위해 운영 계정을 만들거나 권한을 약화하지 않는다.

## 배포와 복구

API/worker를 같은 새 버전으로 먼저 배포하고 추가 007–011을 적용한 뒤 새 UI를 배포한다. 001–006의 파일과 checksum은 유지한다. 온라인 DB+비공개 첨부 bundle을 새 경로로 백업하고, 최신 신뢰 가능한 복구 원장을 대조한 별도 복구본에서 확인한다. 현재 원장보다 오래된 승인·보류·계정 상태를 복원하지 않는다. 최신 신뢰 원장이 없어 복구가 거절되면 우회하지 않고 별도 보관 원장을 확보한다. 운영 데이터 삭제/초기화·커밋·push·실제 배포는 수행하지 않았다.
