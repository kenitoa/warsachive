# 출시 기준과 증거

- [ ] 기록의 관련성·출처·서지·독립성·사용권을 검토한다.
- [ ] source-checked와 사람의 승인을 화면과 데이터에서 구분한다.
- [ ] 원본 수집 자료를 보존하고 미확인 자료를 공개 검색에서 제외한다.
- [ ] npm run lint/typecheck/test/content:gate/build/test:static/test:browser가 통과한다.
- [ ] 검색 → 필터 → 상세 → 근거 → 원문 → 뒤로가기가 동작한다.
- [ ] 빈 결과·저장 실패·손상 저장소·미공개 자료를 명확히 처리한다.
- [ ] 북마크·메모·최근 기록은 저장된 기기 범위와 복구 방식을 표시한다.
- [ ] 모바일·키보드·스크린리더·글자 확대를 실제 환경에서 확인한다.
- [ ] Pages basePath에서 모든 자산과 metadata/canonical/RSS/sitemap이 일치한다.
- [ ] 공개 release SHA와 콘텐츠 hash가 기대 산출물과 일치한다.
- [ ] 이전 승인 버전으로 복구하는 절차를 운영자가 수행할 수 있다.
- [ ] GitHub 권한·브랜치 보호·실제 Pages 배포·원문 링크 상태를 확인한다.
- [ ] 모바일 실제 기기·오프라인 재실행·외부 링크·공유·기기 저장을 확인한다.
- [ ] 의존성 감사의 미해결 항목을 검토하고 노출 경로를 기록한다.
- [ ] 계정 세션·CSRF·소유권·버전 충돌과 탈퇴 전 공동 소유권 이전을 확인한다.
- [ ] 서로 다른 작성자/검수자의 실제 승인과 정확한 contentHash를 확인한다.
- [ ] `npm run test:withdrawal`로 모든 자료가 보류되어도 정적 빌드·기존 주소·공개 데이터 경계가 유지되는지 확인한다.
- [ ] 비공개 근거 파일을 공개 경로와 분리하고 DB와 파일을 함께 백업·새 경로 복구한다.
- [ ] 웹/API 같은 사이트·HTTPS·쿠키·origin과 실제 Linux 비루트 컨테이너를 확인한다.
- [ ] 실제 결제 sandbox의 결제·취소·부분 환불·중복/역순 webhook·미확정 결과 복구를 확인한다.
- [ ] AI 실제 평가 보고와 사용자별/서비스 일일 한도·출력 상한을 확인한다.
- [ ] 실제 기관 허락·번역 승인·좌표 근거가 있는 자료만 해당 뷰어·언어·지도에 추가한다.

자동 브라우저·axe 검사와 모바일 번들은 사람의 사용성·실제 기기·접근성 전체를 보증하지 않습니다. GitHub Actions 파일을 작성한 것과 실제 워크플로가 실행된 것은 별도입니다. 외부 분석·Search Console·앱 스토어·NAS 자동 발행의 권한과 실행 결과가 없으면 미검증으로 남깁니다.

이번 의존성 갱신은 지원되는 ESLint 10, typescript-eslint, React hooks/Next lint 플러그인, Playwright, axe 및 Expo 55 권장 AsyncStorage를 사용합니다. 호환 가능한 npm audit fix를 적용했으며 강제 Expo/RN 주요 버전 변경은 하지 않습니다. 전체 도구 트리의 경고와 웹 운영 의존성 검사는 구분해 보고합니다. 검사 수치는 실행 시점마다 달라질 수 있습니다.
